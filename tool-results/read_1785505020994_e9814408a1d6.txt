    52→    52→
    53→    53→#### Products (3 files)
    54→    54→- **`GET/POST /api/products`** — List products with pagination (page/perPage), search (name/barcode/sku), filter (categoryId, isActive, branchId), sorting (sortBy/sortOrder). Includes category and branch relations. POST creates product with Zod validation.
    55→    55→- **`GET/PUT/DELETE /api/products/[id]`** — GET single product with relations. PUT updates with partial validation. DELETE performs soft delete (sets isActive=false).
    56→    56→- **`GET /api/products/barcode/[barcode]`** — Find active product by barcode. Returns 404 if not found or inactive.
    57→    57→
    58→    58→#### Categories (2 files)
    59→    59→- **`GET/POST /api/categories`** — GET returns all categories ordered by name with product count. POST creates with name validation.
    60→    60→- **`GET/PUT/DELETE /api/categories/[id]`** — Full CRUD. DELETE checks for related products before deleting.
    61→    61→
    62→    62→#### Suppliers (2 files)
    63→    63→- **`GET/POST /api/suppliers`** — Paginated list with search (name/phone/email). POST with email validation.
    64→    64→- **`GET/PUT/DELETE /api/suppliers/[id]`** — Full CRUD. DELETE checks for related purchases.
    65→    65→
    66→    66→#### Customers (2 files)
    67→    67→- **`GET/POST /api/customers`** — Paginated list with search, includes transaction count. POST with email validation.
    68→    68→- **`GET/PUT/DELETE /api/customers/[id]`** — Full CRUD. DELETE checks for related transactions.
    69→    69→
    70→    70→#### Transactions (3 files)
    71→    71→- **`GET/POST /api/transactions`** — GET with pagination, search by invoice number, filter (status, paymentMethod, date range via startDate/endDate, branchId). Includes user, customer, items, branch relations. POST creates transaction with auto-generated invoice number, deducts stock for completed sales, restores stock for refunds, adds member points for customers.
    72→    72→- **`GET/PUT /api/transactions/[id]`** — GET with all relations. PUT supports completing held transactions (deducts stock, adds member points) and cancelling completed transactions (restores stock).
    73→    73→- **`GET /api/transactions/held`** — Returns all held transactions for a specific user (query param: userId).
    74→    74→
    75→    75→#### Purchases (2 files)
    76→    76→- **`GET/POST /api/purchases`** — GET with pagination, search, filter (status, supplierId, date range). POST creates purchase with auto-generated PO number, updates product stock and costPrice for received purchases.
    77→    77→- **`GET/PUT/DELETE /api/purchases/[id]`** — PUT supports receiving pending purchases (updates stock). DELETE restores stock for received purchases before deleting.
    78→    78→
    79→    79→#### Stock (2 files)
    80→    80→- **`GET/POST /api/stock`** — GET lists stock adjustments with pagination, filter by type/productId. POST creates adjustment (in/out/adjustment/opname) and updates product stock accordingly.
    81→    81→- **`POST /api/stock/opname`** — Sets actual stock count for a product, creates opname adjustment record with previous/new stock difference.
    82→    82→
    83→    83→#### Settings (3 files)
    84→    84→- **`GET/PUT /api/settings`** — GET returns all store settings as key-value pairs. PUT accepts `{ settings: { key: value } }` object and upserts each setting.
    85→    85→- **`GET/PUT /api/settings/tax`** — Manages tax settings (isEnabled, percentage, mode, applyToAll, categoryId). Creates default if none exists.
    86→    86→- **`GET/PUT /api/settings/service-charge`** — Manages service charge settings (isEnabled, percentage). Creates default if none exists.
    87→    87→
    88→    88→#### Dashboard (1 file)
    89→    89→- **`GET /api/dashboard`** — Returns comprehensive stats in a single response: todaySales, monthSales, totalRevenue, totalProducts, totalCustomers, totalSuppliers, totalTransactions, topProducts (top 5 by quantity), recentTransactions (last 10), lowStockProducts (stock <= minStock), salesChartData & revenueChartData (daily totals for last 30 days with zero-fill for missing dates).
    90→    90→
    91→    91→#### Reports (1 file)
    92→    92→- **`GET /api/reports`** — Supports 9 report types via `type` query param: daily, weekly, monthly, yearly (sales transactions with summary), best_selling (top 20 products by quantity), profit_loss (revenue vs cost of goods sold), customer (spending ranking), supplier (purchase ranking), stock (inventory valuation with low stock alerts). Supports date range (startDate/endDate) and branchId filters.
    93→    93→
    94→    94→#### Branches (2 files)
    95→    95→- **`GET/POST /api/branches`** — GET returns all branches with relation counts. POST creates branch.
    96→    96→- **`GET/PUT/DELETE /api/branches/[id]`** — Full CRUD. DELETE checks for related users/products/transactions.
